# Дневники Ишимуры

Неофициальная фанатская повесть в десяти главах по мотивам вселенной Dead Space. История и персонажи оригинальны; приложение не связано с правообладателями. Текст также доступен в файле [BOOK.md](BOOK.md).

## Android-приложение

Книга полностью встроена в приложение и не требует интернета или разрешений. Листайте страницы свайпом или нажатием на левую/правую сторону страницы; доступны кнопки навигации, содержание и изменение размера шрифта. Место чтения сохраняется автоматически. Нумерация и разбиение страниц пересчитываются под размер экрана и шрифт.

Приложение предназначено для Android 6.0 и новее. Скопируйте APK на устройство, откройте файл и при необходимости разрешите установку из этого источника. Тестовые сборки, сделанные с разными отладочными ключами, нельзя установить одну поверх другой: может потребоваться удалить старую версию (данные чтения при этом удалятся). Запуск на устройстве или эмуляторе в этом окружении не проверялся.

### Сборка на GitHub

При отправке изменений в GitHub автоматически запускается workflow **Android APK**. Откройте вкладку **Actions**, выберите успешный запуск и скачайте архив **Ishimura-Diaries-debug** в разделе **Artifacts**. Распакуйте архив и установите `app-debug.apk` на устройство. Артефакт хранится 30 дней; сборку можно запустить повторно через **Run workflow**. Для скачивания артефактов может потребоваться вход в GitHub.

### Локальная сборка APK

Нужны JDK 17 и Android SDK с платформой API 35. Откройте проект в Android Studio и дождитесь синхронизации Gradle либо выполните:

```sh
./gradlew assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`. Для установки на устройство включите установку приложений из выбранного источника; debug-сборка подписана стандартным отладочным ключом и не предназначена для публикации в магазине.
